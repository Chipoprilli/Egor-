# Фактические результаты проверки

Дата: 28.09.2026.

## Выполнено успешно

- Проверка синтаксиса всех 6 PHP-файлов официальным PHP 8.4.26 для Windows: ошибок нет.
- Проверка синтаксиса public/assets/app.js и tests/integration.mjs средствами Node.js: ошибок нет.
- Приложение запущено встроенным PHP-сервером на 127.0.0.1:8000.
- Автоматический HTTP-тест tests/smoke.mjs прошёл: регистрация и вход открываются (200); защищённые страницы перенаправляют гостя на login (303); API возвращает гостю 401; сервер отклоняет пустое имя, неверный email и короткий пароль (422); неверный CSRF отклоняется (403); конфигурация и SQL не доступны через веб-корень (404); собственный CSS доступен (200).
- Форма регистрации открыта в браузере и визуально проверена в узкой панели около 570 px: Bootstrap загружается, поля и кнопка отображаются корректно, иллюстративная колонка скрывается по адаптивному правилу.

Повтор базовых проверок при запущенном сервере:

```sh
node tests/smoke.mjs http://127.0.0.1:8000
```

## Не выполнено в доступном окружении

MySQL не установлен/не обнаружен. Поэтому миграция, фактическая запись в MySQL, успешный вход и CRUD с двумя пользователями здесь не проверены исполнением. Для этого поставляется tests/integration.mjs; его нужно запускать после настройки MySQL и миграции по README. Сценарии подтверждения удаления и все страницы кабинета при размерах 1366×768 и 390×844 также остаются для локальной приёмки.

Наличие исходного теста не означает, что он выполнен. Эта поставка не содержит утверждений о пройденном полном интеграционном тесте.
